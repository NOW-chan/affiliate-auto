# SNS告知文の作り方

## 手順

1. `articles/<id>/article.html` と `meta.yaml` を読み、読者にとっての価値を1つに絞る
   （例：「◯◯と△△の料金の違いが3分でわかる」）。
2. 次の形式で `articles/<id>/sns.yaml` を書く。**URL は書かず、`{URL}` と書く**（スクリプトが公開URLに置き換える）。

```yaml
threads: |
  （本文）
x: |
  （本文）
```

## Threads のルール

- 500文字以内（`{URL}` は30文字として数える）
- 構成：1行目で悩みに共感 → 記事でわかること（箇条書き2〜3点）→ `{URL}` → 最後の行に `#PR`
- 絵文字は2個まで

## X のルール

- 全角140字以内
- **初期設定ではリンクを入れない**（リンク付き投稿は API 料金が高いため）。
  記事の要点を1つ、それだけで役に立つ形で書き、最後に「詳しくはプロフィールのブログで」と書く。
- 環境変数 `X_INCLUDE_LINK=true` と指示された場合のみ `{URL}` を入れてよい
- 最後に `#PR` を入れる

## 共通の禁止事項

- 一人称の利用体験（「使ってみた」「愛用中」など）
- 「絶対」「必ず」「誰でも稼げる」などの誇大表現
- 効果効能の断定（育毛・美容・健康系）
- 同じ文面の使い回し（毎回、切り口を変える）
